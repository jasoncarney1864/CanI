# 1. Vision & goals

CanI is a personal RAG platform that helps people understand the documents that already govern their lives — HOA agreements, leases, lab results, insurance policies — but that nobody reads until they need something specific from them. The platform answers narrow, personal, document-grounded questions ("What time can I walk my dog per my HOA rules?" or "What does this specific lab value mean for me?") rather than general legal or health questions.

Secondary goal: this project is a deliberate vehicle for the owner to build hands-on depth in Azure, AKS, Pulumi (Python), Azure Landing Zone patterns, GitHub Actions, and Azure Monitor. Some architecture choices below intentionally favor learning value over the "easiest" path (e.g., AKS over Azure Container Apps).
