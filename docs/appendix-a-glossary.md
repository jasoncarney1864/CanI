# Appendix A — Glossary

- **Hub** — CanI's central identity, authorization, and routing service.
- **Spoke** — a vertical or platform application registered with the hub (CanI Docs, CanI Legal, CanI Health, future verticals).
- **ALZ** — Azure Landing Zone, Microsoft's reference architecture for enterprise-scale Azure environments.
